# GAPS website

The site is a static Astro website for the Signal Processing Applications Group at Universidad Politécnica de Madrid.

## Local development

Requires Node.js 22.22 or later.

```sh
npm install
npm run dev
```

Create the production files with `npm run build`; Astro writes them to `dist/`. Preview that build with `npm run preview`.

## Content locations

- Pages and layouts: `src/pages/` and `src/layouts/`
- People profiles and long-form page content: `src/content/`
- Site data: `src/data/`
- Public images, documents, styles, scripts, and the talk map: `public/`

See [CONTRIBUTING.md](CONTRIBUTING.md) for the main edit paths.
